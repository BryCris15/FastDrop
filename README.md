# FastDrop
# Tecnologías Utilizadas

## Frontend Móvil
* **React Native (Expo):** Entorno principal para el desarrollo de la aplicación móvil multiplataforma.
* **Zustand:** Librería para la gestión del estado global del cliente móvil.
* **React Query:** Herramienta para la gestión de caché, sincronización y peticiones de datos asíncronos.

## Backend y Base de Datos
* **Supabase:** Plataforma de Backend as a Service utilizada como infraestructura principal del lado del servidor.
* **PostgreSQL:** Sistema de gestión de bases de datos relacionales para la persistencia de datos.
* **Supabase Auth:** Componente encargado de la autenticación y control de accesos mediante tokens JWT.
* **Supabase Edge Functions:** Funciones serverless para la ejecución de la lógica de negocio aislada.
* **Supabase Realtime:** Mecanismo basado en WebSockets para la escucha y transmisión de datos en tiempo real.
* **Supabase Storage:** Repositorio dedicado al almacenamiento de archivos estáticos y multimedia.

## Integraciones y Servicios de Terceros
* **Firebase Cloud Messaging (FCM):** Servicio utilizado para la gestión y envío de notificaciones push transaccionales.
* **OpenStreetMap:** API de mapas integrada para la definición de rutas y localización de puntos de entrega.

## Diseño y Gestión del Desarrollo
* **Figma:** Herramienta utilizada para el diseño de la interfaz de usuario, pantallas y componentes.
* **Trello:** Plataforma empleada para la gestión, organización y seguimiento de tareas del proyecto.
* **GitHub:** Sistema de control de versiones distribuido para el alojamiento del código fuente.

## Pruebas y Despliegue
* **Expo Go:** Aplicación cliente para la visualización y pruebas rápidas del código en entornos locales de desarrollo.
* **Expo CLI:** Interfaz de línea de comandos utilizada para la ejecución de procesos de automatización y compilación local.
